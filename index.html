使用场景

流媒体与内容访问

需要稳定观看海外平台时，优先选择旗舰版。该方案强调全节点原生解锁，减少因公共线路被识别而导致的加载失败。基础版可覆盖常见站点的基础解锁需求。

游戏与实时对战

旗舰版含 IPLC 专线游戏加速优化，适合对延迟和丢包更敏感的场景。选择距离更近或标注游戏优化的节点，再配合系统代理即可。

远程办公与资料检索

访问协作文档、代码仓库或学术资源时，稳定的长连接比单纯追求峰值带宽更重要。海豚湾将常用办公与学习站点纳入日常线路维护范围。

家庭共用与小团队

设备超过 5 台或需要统一路由策略时，使用团队版。20 台同时在线与定制路由，便于把订阅集中管理，而不是给每台设备单独寻找加速器。

配置流程与操作说明

海豚湾采用标准机场订阅：一次复制链接，客户端自动拉取节点。请按下列顺序操作，可减少导入失败。

第一步：确认套餐与设备数量

对照同时在线台数与月流量。个人浏览选基础版；需要原生流媒体或游戏线路选旗舰版；多人共用选团队版。年付适合长期使用。

第二步：在官网获取订阅链接

登录海豚湾控制台后，复制通用订阅地址（常见为 Clash / V2Ray / Surge 兼容格式）。不要把订阅链接公开发布，避免流量被盗用。

第三步：安装对应系统客户端

Windows 与 Android 常用 Clash Meta 系客户端；macOS 可用 Clash Meta 或 Surge；iOS 常用 Shadowrocket、Stash 或 Quantumult X。软件请从各项目官方发布渠道获取。

第四步：导入订阅并更新

打开客户端的订阅或配置页，粘贴海豚湾订阅 URL，保存后点击更新。成功后节点列表会出现分区名称，例如普通线路、IPLC、流媒体等。

第五步：选择节点并开启系统代理

先选延迟较低的节点，再开启 HTTP/SOCKS 或 TUN 模式。浏览器或游戏即可走加速通道。若某节点失败，更新订阅后换一条线路即可，无需重装。

常见问题

如何确认自己访问的是海豚湾官网？

认准品牌名称「海豚湾(Dolphin)」以及本页公开的套餐、配置与客户端说明。官方不会通过陌生链接索要账号密码。收藏本站入口后再登录控制台复制订阅，可降低钓鱼风险。

机场订阅和普通单一 VPN 有什么不同？

海豚湾以机场订阅交付节点：客户端定时更新线路，您可按延迟、解锁能力切换。传统单一 VPN 往往只有固定入口。订阅模式更适合需要同时覆盖浏览、流媒体和游戏的用户。

客户端应该从哪里下载才安全？

请从 Clash、Shadowrocket、Surge、Quantumult 等软件自己的官方发布页或应用商店获取。海豚湾提供订阅与导入步骤，不在页面分发安装包，也不要求您关闭系统安全功能。

三个套餐分别适合谁？

基础版面向流量和设备都不多的个人用户，含 100GB 与 3 台设备。旗舰版适合需要原生流媒体与 IPLC 游戏优化的用户，含优先工单。团队版面向 20 台设备、高流量和定制路由的小团队。

连不上节点或流媒体失败时怎么处理？

先在客户端更新订阅，更换同区域其他节点，并确认系统时间准确、代理模式已开启。流媒体请使用旗舰版标注解锁的线路。若仍失败，旗舰与团队用户可通过优先工单反馈节点名称与错误提示。

流量如何计算，用完后还能上网吗？

套餐流量按月度额度统计，实际规则以控制台显示为准。用尽后加速通道会受限，可升级到更高套餐或等待下一周期重置。年付只是支付方式优惠，不改变每月额度结构。
